# 默认路线标题规则

## 1. 文档用途

本文档汇总当前默认路线 `Haul Generic Variation` 的 Amazon Item Name 生成、父子体处理和交付前自检规则。

适用对象：

- Parent 父体标题。
- Child 子体标题。
- `item_name[marketplace_id=ATVPDKIKX0DER][language_tag=en_US]#1.value` 字段。
- 与标题联动的 `title_differentiation` / Item Highlight 字段。

规则优先级：实际写入以 `app/template_writer.py` 和 `app/variation_title_rules.py` 为准，实际自检以 `app/template_validator.py`、`app/listing_rules.py` 和 `config/listing_rules.json` 为准。

## 2. 默认标题规格

| 项目 | 当前规则 |
|---|---|
| 语言 | 英文 |
| 项目目标长度 | 100-125 字符 |
| 硬性上限 | 125 字符 |
| Amazon 官方方向 | 非媒体类标题向 75 字符以内迁移 |
| 当前项目取舍 | 仍生成 100-125 字符长标题，但超过 75 字符时 Item Highlight 必须留空 |
| 大小写 | Title Case；介词、冠词、连词可小写 |
| 关键词 | 核心商品词靠前，自然覆盖长尾词、用途、场景和可感知属性 |
| 标点 | 优先使用英文逗号分隔语义段，允许必要的连字符或括号 |
| 重复词 | 除允许小写词外，同一单词不得超过两次 |
| Generic 路线 | 标题不出现供应商品牌、公司名或未授权品牌词 |

允许小写的词：

```text
a, an, and, as, at, but, by, for, from, in, into, nor, of, on, or, per, the, to, with
```

标题应保持像正常商品名，不全大写，不堆砌关键词，不直接照抄竞品标题。

## 3. 标题内容结构

推荐按以下顺序组织：

```text
[多件装/套装前缀] 核心商品词, 次级商品词或形态, 适用对象, 用途或场景, [父体总结词 / 子体属性]
```

可写内容：

- 商品类型。
- 款式、形状、普通材质等可感知属性。
- 真实适用对象。
- 真实用途和使用场景。
- 与字段一致的颜色、尺寸、数量或套装信息。

不写“让身体、皮肤、牙齿、空气或环境更健康、更干净、更安全”等结果型表达。

## 4. Parent 父体标题

Parent 标题不直接继承第一条 Child 标题。系统会从全部 Child 中选取可用的通用标题骨架，去掉子体专属属性，再生成可覆盖整个变体家族的总结标题。

规则：

- 不写某个子体专属的单一颜色、尺寸或款式。
- 存在两个或以上不同 `color` 值时，标题追加 `Multiple Colors Available`。
- 存在两个或以上不同 `size` 值时，标题追加 `Multiple Styles Available`。项目当前使用 `size` 字段承载尺寸或部分款式属性，因此总结词固定为 `Multiple Styles Available`。
- 颜色和尺寸/款式都存在多个值时，两个总结词都追加。
- 如果实际差异是款式，不得为了触发多色标题而虚构颜色差异。
- 有多件装或套装时，数量前缀放在标题首位。
- 总长度不得超过 125 字符。

结构示例：

```text
50 Pcs 2 Set Floral Card Holder Picks, Flower Bouquet Card Sticks for Table Centerpieces, Multiple Colors Available
```

## 5. Child 子体标题

Child 标题使用全变体共用的标题骨架，并在末尾追加该子体自身的属性。

规则：

- 变体主题包含颜色时，Child 标题必须包含它自身的 `color` 值。
- 变体主题包含尺寸时，Child 标题必须包含它自身的 `size` 值。
- 同时有颜色和尺寸时，当前生成顺序为先 `color`，后 `size`。
- 不得包含 `Multiple Colors Available` 或 `Multiple Styles Available`。
- 有多件装或套装时，数量前缀放在标题首位。
- 颜色、尺寸、数量和套装文案必须与对应模板字段一致。
- 总长度不得超过 125 字符。

结构示例：

```text
50 Pcs 2 Set Floral Card Holder Picks, Flower Bouquet Card Sticks for Table Centerpieces, Gold
```

## 6. 多件装和套装前缀

可识别单位：

```text
Pc, Pcs, Piece, Pieces, Pack, Packs, Set, Sets, Pair, Pairs, Count, Ct
```

当前标准化结果：

- `pc` / `pcs` / `pieces` 转为 `Pcs`。
- `pack` / `packs` 转为 `Pack`。
- `set` / `sets` 转为 `Set`。
- `pair` / `pairs` 转为 `Pair`。
- `count` / `ct` 转为 `Count`。
- 纯数字 `set_count` 大于 1 时，生成 `N Pack`。
- 数字为 1 时不强制生成包装前缀，除非原标题已以可识别的数量开头。
- 父体优先使用全部子体共同的包装前缀。

示例：

```text
50pcs 2set  ->  50 Pcs 2 Set
3 packs     ->  3 Pack
2           ->  2 Pack
```

## 7. 长度裁剪规则

父子体标题合成后超过 125 字符时，系统优先保留：

1. 多件装/套装前缀。
2. Parent 总结词或 Child 属性后缀。
3. 通用标题骨架的前部核心内容。

系统会从通用标题骨架的末段开始逐词删减；必要时删除整个末段。裁剪后仍必须人工确认语义完整、核心商品词未被破坏。

> 注意：当前合成器只保证不超过上限，不会自动把裁剪后标题扩展到 100 字符。交付前自检会将低于 100 字符的标题报错。

## 8. Item Highlight 联动

- 当 Item Name 超过 75 字符时，`title_differentiation` / Item Highlight 必须留空。
- 当前默认标题为 100-125 字符，因此默认不填 Item Highlight。
- 只有当用户明确选择 75 字符以内的短标题时，才可考虑填写 Item Highlight。
- Parent 行的 Item Highlight 始终按当前默认规则留空。

Amazon 报错 `100476` 的项目已知解读：只要填写 Item Highlight，Item Name 就必须不超过 75 字符。

## 9. 字符和格式禁止项

### 9.1 Amazon 高风险特殊字符

```text
! $ ? _ { } ^ ¬ ¦
```

除明确属于合法品牌名外，不得使用。Generic 路线通常不存在品牌名例外。

### 9.2 装饰或网页噪音字符

```text
~ # < > * | ;
```

### 9.3 中文或全角标点

```text
， 。 ； ： 、 【 】 （ ） 《 》
```

### 9.4 其他格式错误

- HTML 标签或实体。
- 换行、制表符、连续多空格。
- 连续重复的英文逗号、句点、斜杠、反斜杠或连字符。
- 双引号。双引号是全 Listing 文案级规则，标题中同样不允许。
- 中文文字。

## 10. 标题禁用内容

### 10.1 促销、平台背书、物流或售后

```text
Free Shipping, 100% Quality Guaranteed, 100% Satisfaction, Best Price, Lowest Price,
Hot Sale, Sale, Discount, Coupon, Limited Time, Clearance, Amazon Choice, Best Seller,
Ships From USA, Fast Delivery, After-Sales, Warranty, Refund, Replacement
```

### 10.2 医疗、护理、清洁、防护或结果型功效

```text
Dental, Teeth Cleaning, Tooth Cleaning, Clean Teeth, Oral Care, Dental Care,
Dental Health, Gum Health, Plaque, Tartar, Bad Breath, Fresh Breath, Health, Healthy,
Therapy, Treatment, Treat, Cure, Prevent, Remove Stains, Eliminate Odor,
Antibacterial, Antimicrobial, Disinfect, Sterile, Kill Bacteria, UV Protection
```

### 10.3 摄入暗示或绝对化成分宣称

```text
Flavor, Edible, Digestible, Food Grade, Non-Toxic, Natural, 100% Natural,
All Natural, Pure, Chemical Free, Safe, Hypoallergenic
```

普通非食品商品表达气味时使用 `Scent`，不使用 `Flavor`。

### 10.4 敏感材质、安全、等级、环保或不含某物宣称

```text
Food Grade, Medical Grade, BPA Free, BPA-Free, Phthalate Free, Phthalate-Free,
Lead Free, Lead-Free, Latex Free, Latex-Free, Formaldehyde Free, Formaldehyde-Free,
Flame Retardant, Fireproof, Waterproof, Biodegradable, Eco Friendly, Eco-Friendly,
Organic, Recycled
```

可以写入经资料证明的普通材质，例如：

```text
Velvet, Plastic, Silicone, Wooden Handle
```

### 10.5 全 Listing 禁用/高风险词对标题的附加约束

`config/listing_rules.json` 中的 `restricted_copy_terms` 对标题、五点和描述的合并文案生效，因此标题同样不得包含其中命中的词。当前重点包括：

- 未授权品牌/IP：`Apple`、`AirTag`、`Samsung`、`Velcro`、`Olympic`、`BlackPink`、`BIRKENSTOCK`、`Marshall` 等。
- 儿童/孕产相关：`Toddler`、`Kids`、`child`、`Children`、`pregnant`、`pregnancy`、`maternity` 等。
- 医疗、杀菌、防护或结果宣称：`medical`、`sterile`、`sanitize`、`disinfect`、`antibacterial`、`antimicrobial`、`anti-odor`、`UV protection`、`magnetic`、`kill`、`eliminate`、`cure`、`treat`、`therapy` 等。
- 项目历史风险或禁用表达：`durable`、`Elegant`、`Perfect Gift`、`Special Gift`、`vibrant`、`Breathable`、`very comfortable` 等。

> 此列表会随 `config/listing_rules.json` 变化。交付时必须以当前配置和自检结果为准，不要只依赖本节摘要。

## 11. 变体主题与前台展示

变体维度是买家实际选择的选项，标题规则必须和前台展示目标一致：

- 颜色、图案等视觉维度可能会影响详情页图片切换。
- 尺寸等非视觉维度通常不改变图片。
- 如果买家应在一个选项中看到“款式 + 尺寸”的合并文案，优先使用模板支持的单一文本维度，例如 `SET_NAME`，并写入 `WARNING Print 1.97 in x 118.11 in` 形式的英文值。
- 只有需要买家分别选择两个维度时，才使用 `SIZE/SET_NAME` 等组合维度。
- 子体顺序由 Amazon 自动决定，不能靠标题或模板字段指定。

## 12. 自动生成的当前实现口径

默认路线在写模板前会对父子体标题运行统一处理：

1. 收集所有 Child 的 `color` 和 `size` 值。
2. 按英文逗号拆分子体原标题。
3. 删除与已知颜色/尺寸值完全相同的独立标题段。
4. 删除已有的 Parent 总结词和已有包装前缀。
5. 在可用候选中选取拼接后最长的通用标题骨架。
6. Parent 追加总结词；Child 按 `color`、`size` 顺序追加自身属性。
7. 若超过配置上限，按第 7 节的方式裁剪。

实现边界：

- 只有独立逗号段与颜色/尺寸完全相同时，才会自动删除该属性。如果属性嵌在更长的语句中，需要人工检查 Parent 是否仍残留单一子体属性。
- 标题生成器只负责重组、属性追加和上限裁剪，不会自动修复所有禁用词、Title Case 或自然度问题。
- “不全大写”是项目文案规则；当前大小写检查器会允许全大写的单词，因此整标题全大写仍需人工拦截。
- 自检对中文文字的检测重点是 CJK 汉字；交付时仍需人工确认全标题是自然英语。

## 13. 交付前自检清单

每条 Parent 和 Child 标题都要检查：

- [ ] 标题为自然英语。
- [ ] 长度在 100-125 字符之间。
- [ ] 超过 75 字符时 Item Highlight 留空。
- [ ] 核心商品词靠前，无明显关键词堆砌。
- [ ] 使用 Title Case，不全大写。
- [ ] 非小写豁免词没有重复超过两次。
- [ ] 不含禁用字符、中文标点、HTML、换行或连续多空格。
- [ ] 不含促销、平台背书、物流、售后、医疗、清洁、防护、摄入暗示或绝对化宣称。
- [ ] 不含敏感材质、安全、等级、环保或不含某物宣称。
- [ ] Generic 路线不含供应商名、公司名或未授权品牌/IP。
- [ ] 标题中的颜色、尺寸、数量和套装信息与字段一致。
- [ ] 多件装/套装标题以数量前缀开头。
- [ ] Parent 不带单一子体专属属性。
- [ ] 多颜色 Parent 包含 `Multiple Colors Available`。
- [ ] 多尺寸/款式 Parent 包含 `Multiple Styles Available`。
- [ ] Child 不含 Parent 总结词。
- [ ] Child 包含与变体主题对应的自身颜色、尺寸或款式。

交付前必须运行项目模板自检：

```bash
python3 run.py check-template "待交付的上传表.xlsx"
```

默认不生成自检报告文件；只有用户明确要求时才加 `--write-report`。

## 14. 规则维护

当以下任一内容改变时，本文档应同步更新：

- `config/listing_rules.json` 中的标题长度、禁用字符或词表。
- `app/variation_title_rules.py` 中的父子体标题组装方式。
- `app/listing_rules.py` 中的标题专项检查。
- `app/template_validator.py` 中的变体标题和 Item Highlight 联动检查。
- 项目默认路线或 Amazon 标题政策变化。
